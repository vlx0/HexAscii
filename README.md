# HexAscii

**Текст ↔ байты** в двоичной, восьмеричной, десятичной или hex.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 6 — «Текст»** · **день 41**.

---

## Что умеет

- два поля: ввод → вывод (как в переводчике)
- системы: **2 / 8 / 10 / 16**
- **Текст → байты** и **Байты → текст** (UTF-8)
- пробелы между байтами, верхний hex
- кнопка ⇄ — поменять местами и направление
- из буфера / вывод в буфер

Перевод на лету, пока печатаешь.

## Запуск

```bat
start.bat
```

или `python -m hexascii` / `run_hexascii.pyw`.
